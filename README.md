# TUMMI-
Geographic Information System (GIS)

TUMMI is the food discovery GIS that lets you discover food in the city you're in! Inspired by Beli's mission and Google Map's user interface, TUMMI currently supports 10 cities, using OSM data and google maps API data to give you up to date information on the variety of food near you.
